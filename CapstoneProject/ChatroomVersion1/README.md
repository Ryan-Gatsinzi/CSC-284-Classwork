# Navigation Controls

## Arrow Key Navigation

To enable arrow key navigation in this application:

1. Ensure the input box is empty (no text entered)
2. Press **Enter**
3. You can now use arrow keys to navigate
4. Up and down arrow keys on the input box will controll scrolling through texts in the chat box
5. right and left arrow keys are for transitioning between input box and room list

Once you're ready to type again, simply hit enter to return to input mode. For that to work, you have to be in the input box, not room list.
